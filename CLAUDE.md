# Remotion Video Editor

Este projeto utiliza React + Remotion para criar vídeos através de código.

## Regras gerais

- Sempre utilizar Remotion para composição e edição.
- Utilizar 30 FPS por padrão, salvo especificação diferente em project.md.
- Utilizar 1920x1080 por padrão para vídeos horizontais.
- Utilizar 1080x1920 para vídeos verticais.
- Criar componentes reutilizáveis.
- Evitar colocar toda a lógica em um único componente.
- Priorizar timing, composição, hierarquia e ritmo.
- Não adicionar efeitos apenas para deixar o vídeo mais chamativo.
- Cada efeito deve possuir uma função visual ou narrativa.
- Nunca copiar literalmente uma referência.
- As referências servem para extrair princípios de direção e edição.

## Referências

As referências em:

public/references/

representam a direção visual/editing style do projeto.

## Gameplay

Quando o projeto for gameplay:

- gameplay deve continuar sendo o elemento principal;
- efeitos devem complementar o gameplay;
- evitar excesso de memes;
- evitar excesso de zoom;
- evitar excesso de legendas;
- utilizar silêncio e pausas quando melhorarem o timing;
- priorizar storytelling e entretenimento.

## Processo

Antes de implementar:

1. entender o project.md;
2. analisar referências;
3. analisar assets;
4. planejar;
5. criar storyboard;
6. implementar;
7. revisar;
8. corrigir;
9. renderizar.
